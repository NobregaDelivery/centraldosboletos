# Motor da Central dos Boletos

Código do Google Apps Script que cada usuário roda na própria conta Google.
Ele lê os boletos no Gmail da pessoa e guarda tudo na planilha dela.

- `Codigo.gs` – código principal
- `Pagina.html` – página antiga (opcional, só o dono abre)
- `appsscript.json` – configuração (ativa o serviço Drive, usado para ler PDFs)

Para instalar, siga o guia de instalação enviado por quem te convidou.
