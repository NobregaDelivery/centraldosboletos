# Meus Boletos

App pessoal para acompanhar boletos que chegam por e-mail.

- A página (este repositório) é publicada pelo GitHub Pages.
- Os dados ficam numa planilha Google, e quem lê os e-mails é um script do Google Apps Script.
- O app só mostra dados depois de digitar a senha do app, que **não** fica guardada neste repositório.
